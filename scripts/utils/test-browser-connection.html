🔍 Test de Conexión al Frontend

Este archivo HTML te ayudará a diagnosticar problemas de acceso al frontend.

📋 Instrucciones:

  1. Haz clic en "Test http://localhost:3000"
  2. Si ves error CORS o Network: El frontend SÍ funciona, es un problema de seguridad del navegador
  3. Si ves error de conexión: El frontend NO está accesible desde tu navegador
  4. Prueba "Abrir Frontend" para intentar acceso directo
