  1. "Error al iniciar la sesión de lectura" (genérico)

┌─────────────────────────────────────────────────────────────┐
│  SOLUCIÓN RÁPIDA (30 segundos)                              │
└─────────────────────────────────────────────────────────────┘

PASO 1: Aplicar fix de migraciones y URLs
  bash fix-reading-simple.sh

PASO 2: Reiniciar frontend (para aplicar cambios de código)
  docker compose restart frontend

PASO 3: Probar endpoints
  bash test-reading-endpoints.sh

¡Listo! El visor PDF debería funcionar.

🛠️ SCRIPTS DISPONIBLES

┌─────────────────────────────────────────────────────────────┐
│ RECOMENDADO - Para la mayoría de usuarios                  │
└─────────────────────────────────────────────────────────────┘

  fix-reading-simple.sh
  → Solución rápida y confiable (30-60 segundos)
  → Sin errores de importación
  → Aplica migraciones y reinicia servicios

  Ejecutar:
    bash fix-reading-simple.sh

┌─────────────────────────────────────────────────────────────┐
│ ALTERNATIVAS                                                │
└─────────────────────────────────────────────────────────────┘

  EJECUTAR_FIX.sh
  → Fix con diagnóstico completo (60-90 segundos)
  → Más información sobre el estado del sistema

  fix-reading-session-error.sh
  → Fix completo con pruebas de endpoint (90-120 segundos)
  → Incluye creación de usuario y token de prueba

  debug-reading-error.sh
  → Solo diagnóstico, no modifica nada (30 segundos)
  → Para ver qué está mal sin hacer cambios

  quick-fix-reading.sh
  → Fix ultra rápido (20-30 segundos)
  → Solo lo esencial, sin verificaciones extras

  test-reading-endpoints.sh ⭐ NUEVO
  → Prueba los 3 endpoints principales
  → Verifica que el fix de URLs funcionó
  → Muestra resumen de tests (passed/failed)

┌─────────────────────────────────────────────────────────────┐
│ WINDOWS - PowerShell/CMD                                    │
└─────────────────────────────────────────────────────────────┘

  FIX_READING_SESSION_ERROR.bat
  → Versión Windows del fix automático

✅ DESPUÉS DEL FIX

1. Abre http://localhost:3000
2. Inicia sesión
3. Ve a la biblioteca
4. Selecciona un libro
5. Haz clic en "Leer"

¡El visor PDF debería funcionar! 🎉

═══════════════════════════════════════════════════════════════

❌ SI EL ERROR PERSISTE

1. Ver logs:
   docker compose logs backend --tail=50

2. Ejecutar diagnóstico:
   bash debug-reading-error.sh

3. Revisar estado:
   docker compose ps

4. Reconstruir (último recurso):
   docker compose down
   docker compose up -d --build
